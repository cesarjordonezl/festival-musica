# 🎵 Festival de Música

Proyecto web de un festival musical, desarrollado como práctica de aprendizaje de desarrollo web. La página presenta información del festival, galería de imágenes, video y sección de programación.

## 📌 Descripción

Este proyecto forma parte de mi proceso de aprendizaje como desarrollador web. Fue realizado siguiendo las explicaciones de un curso y me ha permitido practicar la organización de archivos, los estilos con Sass y la automatización de tareas con Gulp.

## 🛠️ Tecnologías utilizadas

* **HTML5:** estructura del sitio web.
* **Sass (SCSS):** organización y generación de estilos CSS.
* **JavaScript:** interactividad de la página.
* **Gulp:** automatización de tareas de desarrollo.
* **npm:** administración de dependencias.
* **Git y GitHub:** control de versiones y publicación del código.

## 📂 Estructura del proyecto

* `index.html`: página principal.
* `src/scss/`: archivos fuente de estilos Sass.
* `src/js/`: código JavaScript.
* `src/img/`: imágenes del proyecto.
* `build/css/`: estilos CSS generados.
* `build/js/`: JavaScript preparado para la página.
* `video/`: archivos de video utilizados en el sitio.
* `gulpfile.js`: configuración de tareas de Gulp.

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio:

   ```bash
   git clone https://github.com/cesarjordonezl/festival-musica.git
   ```

2. Entra en la carpeta:

   ```bash
   cd festival-musica
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Abre `index.html` con un servidor de desarrollo local, por ejemplo, la extensión Live Server de Visual Studio Code.

> Para recompilar los estilos o ejecutar tareas automatizadas, revisa los scripts definidos en `package.json`.

## 📚 Propósito educativo

Este repositorio corresponde a un ejercicio realizado siguiendo un curso de desarrollo web. Su objetivo es practicar tecnologías de frontend y familiarizarme con herramientas utilizadas en proyectos web.
